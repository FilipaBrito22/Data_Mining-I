# Employee Absenteeism Analysis – Data Mining I

## Project Overview

This project focuses on analysing employee absenteeism patterns in a Brazilian courier company using data mining techniques.

The main objective was to identify groups of employees with similar absenteeism behaviours through clustering, helping the company better understand the factors associated with employee absences and support data-driven HR decisions.

## Objectives

- Explore and understand employee absenteeism data through Exploratory Data Analysis (EDA).
- Clean and preprocess the dataset, addressing missing values, outliers and feature transformations.
- Apply clustering techniques to identify meaningful employee segments.
- Evaluate and interpret the resulting clusters.
- Translate analytical findings into actionable insights through data visualization.

## Methodology

The project followed three main stages:

**1. Data Exploration and Preprocessing**
- Exploratory Data Analysis (EDA).
- Data cleaning and preprocessing.
- Feature analysis and transformations.

**2. Employee Segmentation**
- Application of clustering techniques, including K-Means.
- Cluster evaluation and interpretation.
- Identification of patterns in employee absenteeism.

**3. Results and Visualization**
- Analysis of the identified employee segments.
- Interpretation of relevant features and absenteeism patterns.
- Development of a Power BI dashboard to support the exploration and visualization of results.
